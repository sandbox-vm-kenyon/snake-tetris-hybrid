# Snake-Tetris Hybrid Mobile Game

A Tetris clone with a twist: every 3-5 pieces, a snake-game snake descends. 
Avoid walls and the ceiling, or the snake will lock into place as a block.

Play the demo here: [https://sandbox-vm-kenyon.github.io/snake-tetris-hybrid/](https://sandbox-vm-kenyon.github.io/snake-tetris-hybrid/)
